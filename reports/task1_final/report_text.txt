Task 1
Frequency-Selective Residual Decay
Advanced Deep Learning project report
MAE on ImageNet-100, with a SiT extension
9 November 2026
Summary
This project changes the identity shortcut inside a transformer block. The original residual-decay method scales the whole shortcut. Our version also keeps part of a local average, so nearby visible patches can retain shared information while the remaining detail still receives the original decay.
We trained five MAE variants for 200 epochs each, starting from scratch. All used the same ImageNet-100 release, model, seed, effective batch size and learning-rate schedule. Final classification evaluation used the complete training split to fit the linear classifier and all 5,000 validation images to measure accuracy.
Study item | Setting
Main model | Custom MAE ViT-B/16 from the supplied repository
Comparisons | Standard shortcuts, fixed decay, uniform beta=0.5, uniform beta=1, Gaussian beta=0.5

Hardware | H200 GPU with a 7 GiB PyTorch allocator limit
Additional study | Three SiT-B/4 variants, also trained for 200 epochs

The Gaussian-like 5x5 filter with beta=0.5 gave the best MAE result: 75.66% linear-probe accuracy and 65.98% KNN accuracy. Fixed decay reached 72.02% and 59.90%. The uniform filter at beta=0.5 also helped, but beta=1 reduced accuracy to 65.28%.
The feature measurements support a tradeoff rather than a simple rule. Beta=1 produced the lowest high-frequency share and rank entropy, yet it did not give the best classifier. Moderate preservation of local structure worked better in this experiment.
These are results from one seed and a resized ImageNet-100 release. The software checks passed, but the final pipeline has not been tested on a physical RTX 3070. The SiT study measures feature quality; it does not establish improved image-generation quality.

1. Method
A shortcut carries a block input directly to its output. Let X be the patch features, a the original shortcut multiplier and L a local average of nearby visible patches. The learned attention or MLP branch is left as it is. We replace only the shortcut term:
S(X) = aX + beta(1 - a)L
Beta is fixed for a run and is not learned. Beta=0 gives exactly the original fixed-decay shortcut. When a=1, the local-average term is zero, which recovers the standard-shortcut control. The same rule is applied to both encoder additions, using the repository's separate attention and MLP multipliers.
X = L + (X - L)
S(X) = [a + beta(1 - a)]L + a(X - L)
This form explains the intention. The part shared with the local average gets a larger coefficient, while the difference from that average keeps multiplier a. With missing patches and image borders, L is a local smoothing operation rather than an exact split into Fourier frequency bands.
The two fixed filters
The uniform filter gives every position in a 5x5 window weight 1/25. The Gaussian-like filter uses the outer product of [1, 4, 6, 4, 1], divided by 256. Its centre receives more weight. Both filters are fixed and add no trainable parameters.

Figure 1. The averaging kernels. The same kernel is applied to the feature grid and the visibility grid.
Using the correct patch positions
At 75% masking, MAE keeps 49 patch tokens from a 14x14 image grid. Those tokens are shuffled and scattered across the image. Treating them as a 7x7 image would put unrelated patches next to one another.
Scatter visible features back into their original 14x14 positions using ids_keep.
Create a grid with 1 at visible positions and 0 elsewhere.
Filter both grids with the same fixed kernel.
Divide the filtered features by filtered visibility, with a small numerical lower bound.
Gather the averages back into the original visible-token order.

2. Implementation and experiment setup
What changed in the model
Only the encoder identity additions use the new rule. CLS, the special summary token, keeps its original scalar shortcut. The MLP addition recomputes L from its own input, after the attention addition has changed the features. Gradients pass through the averaging operation. The decoder, learned attention and MLP operations, initialization and reconstruction loss are unchanged.
The unmasked feature-extraction path uses the same rule on the complete grid. Kernel choice, beta and the original decay setting are saved with checkpoints and restored on load. Each MAE variant has 117,038,848 trainable parameters.
Dataset and baseline
We used the approved clane9/imagenet-100 release at revision 0519dc2f402a3a18c6e57f7913db059215eee25b. It contains 126,689 training and 5,000 validation images. The 100 CMC class IDs and their integer labels are fixed in Appendix A. Preparation records contain SHA-256 checksums for all 18 source shards.
The source images were resized to 160 pixels on the shorter side before our transforms. They are therefore not the original full-resolution ImageNet images. The teammate's earlier run was not independently verified. Our baselines are newly trained matched controls on this approved release.

Fixed decay improves linear-probe accuracy by 5.10 percentage points over standard shortcuts. The uniform beta=0.5 variant adds 1.68 points over fixed decay. Evaluation choices
We kept the repository's pooling: average all final raw encoder tokens, including CLS, without an added output normalization. Extraction uses fixed resize/centre crops and no masking, in batches of 8. The probe runs on CPU for 200 epochs with AdamW, batch 1024, learning rate 0.01 and the existing cosine schedule. Its default weight decay is 0.01. KNN uses cosine-normalized features, k=20 and vote temperature 0.07.
Earlier probes used only 1,000 training and 1,000 validation images. Their scores were 34.7%, 44.6% and 52.3% for the first three methods. Those subset results are retained in the logs, but the full-data results above are the final comparison.

5. Measuring rank and spatial frequency
Rank entropy
For the same 200 validation images, we collect the CLS vector at each encoder block. Rows of Z are images and its 768 columns are channels. Each row is centred across channels, then we form sample-by-sample covariance:
C = Zc Zc^T / (768 - 1)
p_i = lambda_i / sum_j lambda_j;    H(C) = -sum_i p_i log(p_i)
The nonnegative eigenvalues lambda_i are the covariance singular values. We use natural logarithms and do not exponentiate H. A smaller value means the covariance spectrum is more concentrated. It is an entropy value, not a literal count of feature dimensions. The metric follows the covariance-based definition requested for this task [1]. Rank is measured after training and never changes the shortcut multipliers.
High-frequency energy and spatial variation
Frequency measurements use complete, unmasked 14x14 patch grids from the same 200 images at every depth. CLS is excluded. We remove each channel's spatial mean and take a 2D Fourier transform. Frequencies with radial magnitude above 0.25 cycles per patch count as high frequency. The high-frequency share is high-frequency energy divided by all non-DC spatial energy.
DC is the constant spatial component. It is removed from both the energy numerator and denominator. We also report absolute high- and low-frequency energy and total spatial energy, averaged over images and summed over channels. Spatial variation is the mean squared difference between horizontally and vertically adjacent patch features. These checks help distinguish a changed frequency balance from an overall change in feature scale.

Uniform beta=0.5 reduces final high-frequency share from 41.28% under fixed decay to 14.14%. Gaussian beta=0.5 reaches 19.32%. Both retain more low-frequency energy than fixed decay. Their total spatial energy is also higher, so the lower shares do not come from shrinking every feature equally.
Beta=1 gives the lowest high-frequency share, 7.69%, and CLS rank entropy, 0.0917, but poorer classification. Gaussian has higher high-frequency share and rank entropy than uniform beta=0.5, yet better linear probing. These results do not support using either lower entropy or stronger smoothing alone as a reliable accuracy predictor. The probe pools all tokens, while the rank measurement uses CLS, which also limits a direct comparison.

6. How the features change across depth

Figure 5. Measurements at all 12 MAE encoder blocks using 200 identical unmasked images. Energy and variation axes use log scales where marked. Low-frequency energy excludes DC. All points come from saved records.
The effect is not uniform across the network. Some active variants have larger variation in early blocks, while the strongest high-frequency suppression appears later. The Gaussian filter retains more short-range detail than the uniform filter in the final features. Its final low-frequency energy is about 43,994, compared with 22,148 for fixed decay.
Uniform beta=1 has very concentrated CLS covariance despite substantial patch-feature energy. Its low rank-entropy value therefore does not show that every patch feature has become uninformative. It does show why the feature type and covariance definition need to remain explicit when discussing rank.
The observed spectral changes are consistent with the intended shortcut mechanism. They do not establish that frequency suppression caused the classification gains. The learned branches can change their behaviour in response to the new shortcut, and all conclusions here come from one training seed.

8. SiT extension
After the MAE study, we applied the same shortcut idea to SiT-B/4. SiT predicts a velocity that moves a noisy compressed image representation towards an image. Its input is a complete 8x8 grid of latent tokens, with no CLS token or missing patches. The shortcut is applied to both encoder and decoder blocks, using the original minimum multiplier 0.8.
All three SiT backbones started from scratch. They share the same frozen stabilityai/sd-vae-ft-ema image compressor, pinned to revision f04b2c4b98319346dad8c65879f680b1997b204a. A VAE is a model that compresses an image into a smaller representation. We cached its mean and log-variance for both image flips, then sampled a fresh latent during each training batch. The compressor weights are shared across methods and are not an MAE pretrained baseline.
SiT used 256x256 inputs, 200 epochs, seed 0, physical batch 64 with four-batch accumulation, AdamW at constant learning rate 0.0001, zero weight decay and FP16 mixed precision. The effective batch remained 256 and the allocator cap remained 7 GiB. EMA weights use a running average of model weights with decay 0.9999. Validation used EMA and fixed noise every five epochs.

9. What the SiT results support

Figure 8. SiT training velocity loss and every completed fixed-noise EMA validation pass. This objective is separate from MAE reconstruction loss.
At the shared setting, frequency-selective decay improves the linear probe by 3.52 points over fixed decay and 2.34 points over the standard control. The scores remain modest. Earlier clean final-block probes gave 9.1%, 9.8% and 9.5% on 1,000 validation images. The new protocol changes the feature layer, noise level and validation sample count, so it is not a direct measure of improvement over that earlier evaluation.

Figure 9. SiT depth measurements from 200 common clean images at t=1. Rank uses mean patch tokens. These are separate from the selected noisy block-9 probe and are not directly comparable with MAE CLS rank.
The clean final-block high-frequency shares are 66.01% for standard shortcuts, 64.24% for fixed decay and 67.27% for frequency-selective decay. The MAE pattern of lower final high-frequency share does not carry over to this SiT measurement. We therefore cannot claim that the same spectral explanation has been established in both models.
SiT peak allocated memory was about 4.69 GiB for all three runs. Their queue finished in 9 hours 22 minutes. No generated-image quality metric was measured. A better linear probe or slightly lower velocity loss does not establish better image generation. SiT also uses class labels during pretraining and a pretrained compressor, so its absolute classifier scores should not be compared with MAE as a controlled architecture comparison.

The published ImageNet-100 setup uses 800 pretraining epochs, batch 1024, peak learning rate 0.0006 and 40 warmup epochs; probing runs for 200 epochs [1, Table 3 and Appendix A]. FID compares generated and real image features; lower is better. For SiT, the residual-decay paper reports FID 16.5 versus 11.8 for its SiT-XL/2 U-Net control and decayed model at 400,000 updates on ImageNet-1K [1, Table 2]. The original SiT paper reports FID 33.0 for SiT-B/2 at 400,000 updates [3]. Our B/4 ImageNet-100 runs have about 99,000 updates and no FID measurement, so these values cannot validate our generation quality.
Conclusions
The main Task 1 result is a useful improvement within our controlled MAE comparison. Gaussian beta=0.5 gives 75.66% linear-probe accuracy, 3.64 points above fixed decay. Uniform beta=0.5 gives a smaller gain. Beta=1 hurts accuracy. The local-average operator and beta both matter.
The frequency measurements show that active shortcuts can preserve more low-frequency energy while reducing the high-frequency share. The strongest suppression is not the best classifier. Rank entropy also fails to order the models by accuracy. These findings support the method as an empirical change, but do not prove a general causal link between frequency, rank and semantic quality.
The implementation, five MAE comparisons, two averaging operators, SiT extension and saved logs/curves are complete. Physical RTX 3070 testing is still pending. Repeated seeds and an untouched test set would be needed for stronger statistical claims; the best MAE variant was identified on the reported validation set. SiT sample generation and FID are also pending if a generation-quality claim is required.

The model runs used Python 3.11.16, PyTorch 2.9.0, torchvision 0.24.0, timm 1.0.29, NumPy 2.2.6 and CUDA 12.8. FlashAttention was unavailable, so the PyTorch SDPA attention path was used.
